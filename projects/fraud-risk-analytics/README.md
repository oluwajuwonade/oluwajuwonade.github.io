# Fraud Risk Analytics

A reproducible demonstration of transaction-risk scoring, chronological validation, threshold selection, and fraud-review trade-offs.

## Run

Install dependencies with pip install -r projects/fraud-risk-analytics/requirements.txt.

Run python projects/fraud-risk-analytics/src/run_analysis.py --rows 12000 --output-dir projects/fraud-risk-analytics/outputs.

The script creates synthetic transactions, fits a logistic-regression model, chooses a decision threshold on a validation window, evaluates on a later holdout, and exports a metrics JSON file plus row-level predictions.

## Metrics

Report average precision (important for imbalanced labels), ROC AUC, precision, recall, F1, false-positive rate, alert rate, and confusion counts. The threshold is selected outside the test set.

## Disclosure and limits

All transaction data and labels generated by this script are synthetic. Metrics validate the analytical workflow only; they do not estimate a bank's production performance. Real deployment would require a representative, authorised dataset, leakage checks, calibration analysis, cost-sensitive thresholding, drift monitoring, and privacy/fairness review. A risk score is not proof that a transaction is fraudulent.
