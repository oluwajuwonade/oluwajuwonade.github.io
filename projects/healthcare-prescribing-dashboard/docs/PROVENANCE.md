# Provenance

## Primary source

Open Data Blend - Prescribing dataset:
https://www.opendatablend.io/dataset/?name=open-data-blend-prescribing

Dataset metadata:
https://packages.opendatablend.io/v1/open-data-blend-prescribing/datapackage.json

## Upstream domain source

Open Data Blend describes the Prescribing dataset as NHS England prescriptions dispensed in the UK.

NHS Business Services Authority:
https://www.nhsbsa.nhs.uk/prescription-data/prescribing-data/english-prescribing-data-epd

## Analytical reference

Open Data Blend's GitHub example demonstrates selective querying of the prescribing data and includes glucose blood-testing reagent analysis by practice and primary-care organisation:
https://github.com/opendatablend/opendatablend-py/blob/master/examples/nhs_england_prescriptions_analysis_pandas.ipynb

## Reproducibility note

Open Data Blend documents that public CSV resources are preview files containing the first 100 rows. This repository therefore stores a compact analytical snapshot suitable for portfolio demonstration rather than claiming to be the complete 2025 prescribing fact table.

## Licence note

The Open Data Blend dataset metadata identifies the data files with the Open Data Commons Open Database License (ODbL-1.0). Review the dataset's current terms and licence before redistributing expanded extracts.
