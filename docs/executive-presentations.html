Retail Sales Performance Diagnostic

A management-facing narrative for investigating a counter-intuitive performance pattern: revenue declines despite an increase in unit volume. It demonstrates metric checks, evidence-led diagnosis, and a time-boxed follow-up plan.

SKILLS DEMONSTRATEDBusiness analysis

KPI definitions, data-quality checks, revenue-driver investigation, and decision framing.

EXECUTIVE OUTPUTAction framework

Separates observed movements from hypotheses and specifies what should be validated next.

Evidence note: this is a synthetic portfolio case. The source figures include a revenue/units/average-selling-price reconciliation issue, so the sample treats it as a metric-definition check instead of claiming a verified causal driver.
